# AgentLine

AgentLine is an AI-native telephony platform. Give your agent a real US phone
number and a human-like voice so it can make and receive calls. Inbound SMS
can be read. Outbound SMS is not enabled for agents.

## What you can build

- **AI phone agents** that answer and place real calls.
- **Outbound dialers** for sales, follow-ups, and reminders.
- **AI receptionists** that answer calls and can transfer the caller to the owner's phone.
- **Inbound SMS** that your agent can read from its number.

## How it works

```
1. Create an agent        POST /v1/agents
2. Buy a phone number     POST /v1/numbers
3. Make / receive calls   POST /v1/calls      (real-time transcription + TTS)
4. Get results            GET  /v1/calls/{id}/transcript  or  webhooks/events
```

Every request is authenticated with `Authorization: Bearer al_live_***`

## FAQ

**How do I get a phone number for my AI agent?**
Sign up at agentline.cloud, provision a US number, and install the AgentLine skill on your agent (OpenClaw, Hermes Agent, or any LLM) — usually under 5 minutes.

**Can my AI agent use one number for calls and SMS?**
The same US number handles outbound calls, inbound voice, and inbound SMS. Outbound SMS is not enabled.

**Do I need Twilio or WebSockets?**
No. AgentLine's relay architecture handles call control, real-time transcription, and text-to-speech for you — your agent just responds with text.

**How much does AgentLine cost?**
US numbers are \$2.00/month per number. Voice calls are \$0.10/minute, billed per second. No monthly platform fees.

**How do agents connect over MCP?**
Point an MCP client at `https://api.agentline.cloud/mcp` with [`mcp-remote`](/guides/mcp) and a Bearer key. `send_sms` and `send_message` are not MCP tools.
