# MCP

The MCP server is `https://api.agentline.cloud/mcp`.

## Claude

Claude (claude.ai, Desktop, Cowork and Claude Code) connects with OAuth: add the
server as a connector, sign in to AgentLine in the window that opens and press
**Allow**. No API key is involved. See [AgentLine for Claude](/claude-connector).

## Other clients

Clients without MCP OAuth connect with `mcp-remote` and a Bearer API key
(`al_live_...`; legacy `sk_live_...` still works).

```json
{
  "mcpServers": {
    "agentline": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@latest",
        "https://api.agentline.cloud/mcp",
        "--header",
        "Authorization: Bearer $AGENTLINE_API_KEY"
      ]
    }
  }
}
```

The server mounts the agent-facing REST operations as tools (21+), including
`create_agent`, `make_outbound_call`, `push_call_context`, `send_sms`, `list_messages`, and
the contacts tools (`create_contact`, `list_contacts`, `update_contact`). See
[Contacts](/guides/contacts).
`release_phone_number` is destructive: it unrents the number from the carrier
and cannot be undone. It is refused while a call or lease is still active.
Texts are sent with `send_sms` (`agent_id`, `to_number`, `body`; optional
`media_url`, `from_number_id`), listed with `list_messages`, and received as
`sms.received` events.
