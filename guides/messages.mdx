# Messages

Inbound SMS arrives on your agent's US phone number. Read it from message
history or from `sms.received` events. **Outbound SMS is not enabled for
agents**, and it is not exposed on MCP (`send_sms` and `send_message` are not
MCP tools).

<Warning>
  `POST /v1/messages` still appears in the API reference because the OpenAPI
  spec includes the operation. Do not send SMS or MMS. The operation is not
  enabled for agents.
</Warning>

## List messages and conversations

<CodeGroup>
  ```python
  client.messages.list(agent_id=agent.id, limit=50)
  client.messages.list_conversations(agent_id=agent.id)
  ```
  ```javascript
  await client.messages.list({ agentId: agent.id, limit: 50 });
  await client.messages.listConversations({ agentId: agent.id });
  ```
</CodeGroup>

`GET /v1/messages` returns inbound texts and stored history. Each entry includes
direction, phone numbers, body, and delivery status.

Inbound messages also arrive through your agent's
[webhook](/guides/webhooks) or the [events](/guides/events) mailbox as
`sms.received`.
