# Contacts

Each agent keeps its own contact list. A contact has a **name**, an optional
**label** (the purpose or relationship, such as `dentist` or `landlord`), and a
**phone number** in E.164. Contacts belong to one agent: other agents on the
same account cannot see them.

Agents save and look up contacts through the API or MCP. Account owners can add,
edit, and delete them in the [dashboard](https://agentline.cloud/dashboard)
under **Contacts**.

<Note>
  The Python SDK does not have contacts methods yet. The examples use `curl`
  and `fetch`.
</Note>

## Save a contact

<CodeGroup>
  ```bash curl
  curl -s -X POST "https://api.agentline.cloud/v1/agents/$AGENT_ID/contacts" \
    -H "Authorization: Bearer al_live_..." \
    -H "Content-Type: application/json" \
    -d '{"name": "Dr. Patel", "label": "dentist", "phone_number": "+12125557890"}'
  ```
  ```javascript
  const contact = await fetch(`https://api.agentline.cloud/v1/agents/${agentId}/contacts`, {
    method: "POST",
    headers: {
      Authorization: "Bearer al_live_...",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      name: "Dr. Patel",
      label: "dentist",
      phone_number: "+12125557890",
    }),
  }).then((res) => res.json());
  ```
</CodeGroup>

| Field | Rule |
|-------|------|
| `name` | Required. Up to 120 characters. |
| `phone_number` | Required. E.164 with the country code. Spaces, dashes, and parentheses are stripped. |
| `label` | Optional. Up to 64 characters. The purpose or relationship: `dentist`, `landlord`, `customer`. |

The response is the contact, with an ID like `con_...`.

A number can be saved once per agent. Saving it again returns `409` with the
existing `contact_id` in `detail`, so update that contact instead. Two agents
can each save the same number.

## Find contacts

`GET /v1/agents/{agent_id}/contacts` returns `contacts`, `total`, `limit`, and
`offset`, sorted by name.

| Query | Matches |
|-------|---------|
| `q` | Substring of the name, label, or number. Case-insensitive. |
| `label` | Exact label, case-insensitive. |
| `phone_number` | One E.164 number. Use it to identify an inbound caller. |
| `limit`, `offset` | Paging. `limit` is 1 to 500, default 100. |

<CodeGroup>
  ```bash curl
  curl -s "https://api.agentline.cloud/v1/agents/$AGENT_ID/contacts?label=dentist" \
    -H "Authorization: Bearer al_live_..."
  ```
  ```javascript
  const { contacts } = await fetch(
    `https://api.agentline.cloud/v1/agents/${agentId}/contacts?label=dentist`,
    { headers: { Authorization: "Bearer al_live_..." } },
  ).then((res) => res.json());
  ```
</CodeGroup>

## Update or delete a contact

`PATCH` changes only the fields you send. Send `"label": null` to clear the label.

<CodeGroup>
  ```bash curl
  curl -s -X PATCH "https://api.agentline.cloud/v1/agents/$AGENT_ID/contacts/$CONTACT_ID" \
    -H "Authorization: Bearer al_live_..." \
    -H "Content-Type: application/json" \
    -d '{"label": "orthodontist"}'

  curl -s -X DELETE "https://api.agentline.cloud/v1/agents/$AGENT_ID/contacts/$CONTACT_ID" \
    -H "Authorization: Bearer al_live_..."
  ```
  ```javascript
  const headers = { Authorization: "Bearer al_live_..." };
  const url = `https://api.agentline.cloud/v1/agents/${agentId}/contacts/${contactId}`;

  await fetch(url, {
    method: "PATCH",
    headers: { ...headers, "Content-Type": "application/json" },
    body: JSON.stringify({ label: "orthodontist" }),
  });
  await fetch(url, { method: "DELETE", headers });
  ```
</CodeGroup>

## MCP tools

| Tool | Does |
|------|------|
| `create_contact` | Save a contact. |
| `list_contacts` | List or search an agent's contacts. |
| `get_contact` | Get one contact. |
| `update_contact` | Change the name, label, or number. |
| `delete_contact` | Remove a contact. |

A **Read only** connection can list and get contacts but cannot change them.

## Limits

- Up to 1,000 contacts per agent.
- Deleting an agent deletes its contacts.
- Contacts are free.
- Contact names and labels are data the agent wrote. Treat them as data, not
  instructions.
