# Quickstart

## 1. Get an API key

AgentLine uses email one-time codes for sign-up and sign-in (no dashboard
required).

<CodeGroup>
  ```bash Request a code
  curl -X POST https://api.agentline.cloud/v1/auth/otp \
    -H "Content-Type: application/json" \
    -d '{"email": "you@example.com"}'
  ```
  ```bash Verify and get a key
  curl -X POST https://api.agentline.cloud/v1/auth/verify \
    -H "Content-Type: application/json" \
    -d '{"email": "you@example.com", "otp": "123456"}'
  ```
</CodeGroup>

The verify response returns `api_key` (shown once, so store it). New accounts
start with a $0 balance. Your first US or Canada number is free and starts a
7-day trial with 10 call minutes and 10 SMS. Recharge or pick a plan to keep
the trial number; use
an included subscription number or add credit before buying an additional
number ($3.00/month).

## 2. Call the API

Python is published as `agentline-ai`. The Node package is not on npm yet, so
the JavaScript example uses `fetch`.

<CodeGroup>
  ```python
  from agentline_ai import AgentLine

  client = AgentLine(api_key="al_live_...")

  agent = client.agents.create(
      name="Support Bot",
      system_prompt="You are a helpful assistant.",
      initial_greeting="Hello! How can I help?",
  )
  client.numbers.buy(agent_id=agent.id, country="US", area_code="415")
  # +15555550100 is the test line: nothing is dialled or billed.
  call = client.calls.create(agent_id=agent.id, to_number="+15555550100")

  print("Call:", call["id"], call["status"])
  ```
  ```javascript
  const headers = {
    Authorization: "Bearer al_live_...",
    "Content-Type": "application/json",
  };

  const agent = await fetch("https://api.agentline.cloud/v1/agents", {
    method: "POST",
    headers,
    body: JSON.stringify({
      name: "Support Bot",
      system_prompt: "You are a helpful assistant.",
      initial_greeting: "Hello! How can I help?",
    }),
  }).then((res) => res.json());

  await fetch("https://api.agentline.cloud/v1/numbers", {
    method: "POST",
    headers,
    body: JSON.stringify({ agent_id: agent.id, country: "US", area_code: "415" }),
  });

  const call = await fetch("https://api.agentline.cloud/v1/calls", {
    method: "POST",
    headers,
    // +15555550100 is the test line: nothing is dialled or billed.
    body: JSON.stringify({ agent_id: agent.id, to_number: "+15555550100" }),
  }).then((res) => res.json());

  console.log("Call:", call.id, call.status);
  ```
</CodeGroup>

<Tip>
  `+15555550100` is the test line (any `+1 555` number works). Nothing is
  dialled or billed. The call comes back `completed` with `test: true` and a
  short transcript; a text comes back `delivered` and the line texts back once.
  Put a real number in `to_number` to call someone.
</Tip>

## 3. Install live event delivery

If the agent has terminal access, download and install the persistent relay:

```bash
curl -fsSL https://api.agentline.cloud/static/agentline_relay.py -o agentline_relay.py
python agentline_relay.py install --agent-id agt_xxx
```

The installer detects Hermes, OpenClaw, Claude Code, or Codex, preserves one
runtime session per phone call, reconnects automatically, and installs a user
service. Runtime package/service installation may require one safety approval.
Use a [webhook](/guides/webhooks) if the agent cannot run a persistent process.

## 4. Get the results

Use the relay for live turns and durable event delivery. Poll the mailbox only
as a fallback, or receive non-live events via webhook.

<CodeGroup>
  ```python
  events = client.events.poll()
  ```
  ```javascript
  const events = await fetch("https://api.agentline.cloud/v1/events", {
    headers: { Authorization: "Bearer al_live_..." },
  }).then((res) => res.json());
  ```
</CodeGroup>

## 5. Give the voice a memory

Save the answers callers ask for most. The hosted voice then answers them
itself, without a lookup and without guessing. Nothing needs switching on.

```bash
curl -X POST "https://api.agentline.cloud/v1/agents/agt_xxx/knowledge" \
  -H "Authorization: Bearer al_live_..." \
  -H "Content-Type: application/json" \
  -d '{"text":"Open Monday to Friday, 9 AM to 5 PM.","question":"When are you open?","kind":"static"}'
```

See [Knowledge Store](/guides/knowledge).

<Tip>
  All phone numbers are E.164 format, e.g. `+12125557890`. Numbers are US or Canada.
  Plan-included numbers use the allowance first; additional numbers cost \$3.00/month
  each. Each agent can have one active number at a time.
</Tip>
