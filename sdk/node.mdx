# Node SDK

The Node package is not on npm yet. `npm i agentline` returns 404. Call the
REST API with `fetch` until a package is published. Python is
`pip install agentline-ai` (`from agentline_ai import AgentLine`).

## Create an agent and place a call

```javascript
const headers = {
  Authorization: "Bearer al_live_...",
  "Content-Type": "application/json",
};

const agent = await fetch("https://api.agentline.cloud/v1/agents", {
  method: "POST",
  headers,
  body: JSON.stringify({
    name: "Support Bot",
    system_prompt: "You are a helpful assistant.",
    initial_greeting: "Hello! How can I help you today?",
  }),
}).then((res) => res.json());

await fetch("https://api.agentline.cloud/v1/numbers", {
  method: "POST",
  headers,
  body: JSON.stringify({
    agent_id: agent.id,
    country: "US",
    area_code: "415",
  }),
});

const call = await fetch("https://api.agentline.cloud/v1/calls", {
  method: "POST",
  headers,
  body: JSON.stringify({
    agent_id: agent.id,
    to_number: "+12125557890",
  }),
}).then((res) => res.json());

await fetch(`https://api.agentline.cloud/v1/calls/${call.id}/hangup`, {
  method: "POST",
  headers,
});

const transcript = await fetch(
  `https://api.agentline.cloud/v1/calls/${call.id}/transcript`,
  { headers },
).then((res) => res.json());

console.log(transcript);
```

<Warning>
  Outbound SMS is not enabled for agents. Do not `POST /v1/messages`. That
  operation is not exposed on MCP. List inbound messages with
  `GET /v1/messages`.
</Warning>

US numbers cost \$2.00/month per number. Voice calls are \$0.10/minute in both
directions. A 0-second call is free. A connected call has a one-minute minimum,
then the actual duration, rounded up to the cent.
